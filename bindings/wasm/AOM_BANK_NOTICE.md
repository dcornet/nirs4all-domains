# AOM descriptor attribution

The F4.3 declarative candidate catalog adapts selected operator names, ordering
and parameter descriptions from Guillaume Beurier's `nirs4all-aom`:
https://github.com/GBeurier/nirs4all-aom/tree/157954dc8c4fbf06e45ed7b421b8a02b007d8331

The pinned repository declares `CECILL-2.1 OR AGPL-3.0-or-later` in
`LICENSING.md`. Catalog provenance records the original commit and source blobs.
Applicable project license texts are distributed with the existing demo notices.
No AOM numerical kernel, Python runtime or optimizer is included. Modified
descriptor mappings and the two explicit SNV/SG chains belong to this Domains
integration. Matching family names/parameters do not assert numerical equivalence
to AOM's boundary conventions or enable its algebraic shortcuts. Actual
preprocessing is performed by the public Methods provider identified in each execution receipt.
