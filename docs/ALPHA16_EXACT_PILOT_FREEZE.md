# Exact pilot freeze and execution gate — alpha.16

No exact real pilot is claimed from incomplete source admission. No real fit
count is invented without the actual admissible component/fold sets. The owner's
alpha.16 resource decision excludes supervised fitting.

The executable protocol already exists in
`nirs4all_domains.confrontation.freeze` and `execute`. A source-specific adapter
must first produce an authorized task, original ownership links, admission
evidence, complete reference/stress/size-control FoldSets and the immutable
H1–H5 binding reference. Freeze only after original-keyed numerical qualification
and a target-access freeze; exclude retained targets from pretraining inputs.

The freeze verifies complete original-to-task ownership, indivisible components,
validation-component identity and grouped inner folds. It pins raw PLS [1,2,3],
raw Ridge [.01,.1,1,10,100], Methods/DAG versions and the actual Methods library
hash. For each outer scope the upper count is `n_inner_folds * 8 + 2` native
candidate/refit fits, summed across every actual design and outer scope.
SNV is separately qualified and costed. FastAOM remains a later option.

Before requesting pilot permission, the protected exact packet must additionally
state target/units, original/canonical hashes, keys, complete membership,
dependency assumptions, stress context, matched evaluation IDs, whole-component
training-size controls, native null/support/range diagnostics, exact fit count,
runtime estimate, peak memory/storage estimate and cumulative campaign headroom.
Do not describe a dimension-based cost estimate as measured peak RAM/runtime.

Only a separate explicit owner approval bound to that pilot ID and cost permits
`execute`. A real executor must use existing shared-journal checkpoints with
opaque HMAC contracts and protected task/OOF artifacts. Failed attempts retain
their reservations. Provider drift, changed freezes, inadequate fit budgets or
missing approval fail before native model calls.

The public executable qualification is:

```console
python -m unittest discover -s tests/integration -p test_confrontation.py -v
```

It exercises actual native grouped PLS/Ridge selection, refitting, training-only
nulls, retained-target mutation and checkpoint reuse on synthetic sources.
It supplies neither real source admission nor real fitting permission.
