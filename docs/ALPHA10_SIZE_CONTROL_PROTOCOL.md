# Additional complete-population size control — domains.size_match.v0.1

Declared after the outcome-blind cardinality audit, before any additional size-
control fit. Historical alpha.9 greedy controls and all alpha.10 primary scores
are immutable. Exhaustive subset-cardinality reachability finds exact component-
safe matches in all six reference-fold/cereal-fold intersections. This is an
additional protocol, without a change to the original three evaluation designs.

For each of the six intersections, select whole context components only from
the original reference training IDs. Match the exact original cereal-holdout
training sample count (150 or 209). Require at least three contexts; maximize
the number of retained contexts, then use the first witness in seed-17 identity-
hash order. Selection cannot inspect X, Y, predictions or model scores. Publish
all selected and evaluation identities before fitting. Keep every evaluation
intersection: together they cover all 359 original development IDs exactly once.

Fit every classical/adaptive configuration already declared in alpha.10,
including historical PLS/fixed Ridge, through the same Methods/DAG or requested
nirs4all FastAOM seam. New inner folds are group-safe and shared across families
within each cell. Hyperparameter grids and operator budgets are unchanged.
Any failure remains a failed complete experiment, without selecting another
subset, retrying a smaller grid or dropping difficult evaluation IDs.

Compare cereal stress to this size-controlled reference on all 359 matched IDs;
also retain the unmodified original reference. Use the same conditional paired
context bootstrap and tolerances as the primary protocol. No new-cereal/refit
uncertainty is claimed. Equal sample count does not equalize cereal composition,
context diversity, target distribution or spectral support; a remaining gap is
not a causal shortcut estimate. No new retained outcomes are accessed.
