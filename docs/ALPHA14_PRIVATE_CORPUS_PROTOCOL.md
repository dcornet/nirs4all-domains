# Authorized confidential corpus — domains.private_corpus.v0.1

Expected behavior, declared before implementation tests or new source processing:

The pinned 164-entry catalog is the screening population. Admission, execution,
publication and independent-study denominators are distinct. Review all 122
private-tier descriptors without reading their restricted source bytes. Access,
local analysis, aggregate publication and raw redistribution each have an
independent evidence-backed state: allowed, denied, unknown or
requires_owner_approval. Explicit prohibition wins. Neither a cache file nor a
software license grants underlying data rights. Preserve the owner's CORN hold.

Local-private analysis needs allowed access and analysis, with evidence, and
resolved permission to handle any sensitive/confidential material. Publication
and redistribution may remain denied. No target or metadata decoder is required
for admitted descriptive X. Unknown physical identities stay observation-only.

Source matrices remain in their authorized original cache. The configured
private evidence root must be outside the Git workspace, not a symlink/reparse
escape, and protected for the owner (plus Windows SYSTEM). Secret material lives
in a separate protected subdirectory. No real private evidence enters fixtures,
CI inputs, package contents, public documentation or automatic Git publication.
The controls protect accidental disclosure through Domains; they do not protect
against an administrator or another program running under the same owner account.

HMAC-SHA256 pseudonyms bind an explicit authorized study/population scope,
identity kind and exact original identifier. Use a random 256-bit local secret,
not a public content hash. Persist and collision-check the reverse mapping only
in the protected identity store. Retries reuse the same secret/scope. Verified
paired views share one relationship scope only under a recorded original-key
relationship proof; unrelated studies keep separate scopes. Dependency and split
membership are mapped as identities, never re-estimated or merged for privacy.

All native computation reuses unchanged Methods/Preflight APIs and the existing
domains.unsupervised.v0.1 geometry. Raw/SNV, complete axes, exact/cost-qualified
query designs, two HDBSCAN settings and the alpha.13 B60 design retain their
original thresholds, tolerances, missingness and scientific interpretation.
No PCA scores persist in compact reports. Detailed labels, neighbor evidence,
panels and fingerprints may remain local. Input/model/source failures produce
fixed safe diagnostic codes; retain successful local evidence if export fails.

P0 reviews all entries. Freeze eligible X-only source priorities by permitted
population diversity, source feasibility and resource cost before P1/P2. No Y
or model score affects selection. P3/P4 remain separately gated; the frozen
H1–H5 and response contracts are unchanged. Unknown reference/assay closure is
a supervised blocker, not a reason to exclude authorized descriptive geometry.
At most one new-study pilot needs its own exact task and reviewed cost.

Real-data execution follows both tested privacy admission and approved resource
policy. Reuse exact inputs/results only with unchanged source/provider/protocol
bindings. Keep cumulative failed reservations and atomic serial publication.
No source/store migration, numerical fallback, new crate or upstream change.

Validation uses deliberately sensitive synthetic records. Required adversaries
cover acquisition gating, target-free execution, scoped and paired identities,
dependency preservation, nested-field smuggling, spectra/scores/neighbors, unsafe
paths/logs/figures, fingerprints/secrets, complementary and cross-release
disclosure, staged files/packages/CI fixtures, review tampering and failed-export
survival. Equality of identities, permission states and content bytes is exact;
native numerical tolerances remain those of alpha.12/13. Passing tests does not
make a private population anonymous or establish biological independence.
