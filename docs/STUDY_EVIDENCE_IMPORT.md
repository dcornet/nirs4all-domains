# Source-study interpretation import

An external literature audit can append records to
`configs/bank/study-evidence.json` under `schemas/study-evidence.v1.schema.json`.
Join by dataset ID, exact content version and source ID. Records carry an
original source URL, evidence level, optional study/population identities,
known dependencies, interpretation and limitations. Unknown identities remain
null. Never derive biological context from a cluster label. Record contradictory
evidence explicitly instead of replacing it with an inferred resolution.

This interpretation layer is separate from immutable X descriptors, memberships
and model outputs. It can group related views/targets for scientific synthesis
without changing those numerical protocols. A citation or imported study ID
alone does not verify biological independence or admit an independent benchmark.
Any revised evaluation design is frozen separately before its outcomes.
No importer scrapes websites, acquires raw data or silently edits Datasets.
