# Deployment-aware validation interpretation v1

Bridge release: **0.1.0a19**. Interpretation protocol:
`domains.validation_intent.v1`. Rust/native numerical versions are unchanged.

Optional content-bound JSON annotations and a Markdown section now explain an
existing report for proof of concept, a known operational context, outside-context
prediction, or three conditional readings when intent is unknown. Dependencies,
factor novelty, X-derived grouping, transduction and spectral-support scope stay
distinct. No universal split recommendation or independent-transfer certificate
is produced. [Usage/API](VALIDATION_INTERPRETATION_API.md) and the
[public tablet example](examples/validation-intent/README.md) are executable.

The feature adds no scientific fit, PCA, raw acquisition, native numerical kernel
or upstream change. Existing numerical report bytes, schemas, defaults and
historical evidence remain intact. Known limitations are caller-supplied
provenance/identity assertions, incomplete dependency metadata and a narrow
computed-state metric adapter; annotation is interpretation, not verification.

The [staged plan](VALIDATION_INTERPRETATION_V1_PLAN.md) freezes scenario behavior
and engineering limits. The [execution receipt](audit/validation-intent-v1-review.json)
records successful local fmt, Clippy with warnings denied, 6 Rust unit and 29
native ignored tests, 390 bridge tests, JSON/schema checks and wheel/sdist source
parity. The final 18 interpretation tests were rerun after review. Windows/Ubuntu
CI execution is pending publication of the implementation commit.

Measured combined usage after local validation: **19,092,928,098 bytes**, up
**1,303,945 bytes**, inside the 512 MiB engineering plan and unchanged
20,289,597,121-byte ceiling. **Budget increases: 0 bytes; new campaign
reservations: 0 bytes.** The campaign remains at 1,793,195,474 of 1,805,306,368
bytes. C:/D: have approximately 154.75/344.40 GB free, above the preserved 2 GiB
reserve per volume. Existing research artifacts and protected history were checked.
