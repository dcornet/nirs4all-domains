# Source-owner requests — alpha.16

The actionable source-specific requests are in the protected local
`alpha16/UNRESOLVED_SOURCE_REQUESTS.md`, linked from the confidential A–J report.
This public document discloses no candidate identity, participation count,
original path, specimen key, reference value or private finding.

Each protected entry identifies:

1. The exact unresolved relationship and the declared original file/converter.
2. Every inspected document and its content receipt, plus exact locator/schema
   results; a basename match remains a lead.
3. The minimal next original file or correspondence needed, local availability
   and whether source-owner clarification is required.
4. Separate consequences for X-only, development-only XY, exploratory prediction
   and independent confirmation.
5. A stopping decision and a next action, conditional on new evidence.

The first unresolved source link is the actionable bottleneck. Later specimen,
assay, units and study-role requirements are conditional prerequisites; they do
not assert that fields are absent from originals that could not be inspected.
No global evidence-absence claim follows from a bounded local investigation.

Use the existing authorized catalog for bounded alternatives after recorded
stopping decisions. Selection uses original availability and provenance leads,
target semantics, dependency evidence and cost. Private or published predictive
performance is excluded. Do not repeat unchanged audits or obtain another broad
spectral collection to avoid a missing original crosswalk.
