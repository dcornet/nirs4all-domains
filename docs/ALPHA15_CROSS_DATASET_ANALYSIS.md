# Cross-dataset structural analysis — alpha.15

This public document describes the analysis method. New confidential source
participation, numerical comparisons, tables and figures have no publication
clearance. They are retained in a separate protected A–J report and are not
presented here as publicly reproducible findings.

The executed synthesis reconciles actual alpha.12/13/14 receipts by catalog ID,
source ID, content hash and numerical protocol. Chronological protocol precedence
is fixed before comparative results: alpha.12, then alpha.13, then alpha.14.
Superseded receipts remain traceable. A historical public profile whose current
analysis permission is unresolved is retained as historical evidence and excluded
from the new calculations. Cards, representations and failed attempts do not
increase the calculated-source or independent-study denominators.

Cache coverage for unexecuted views is based on file presence and declared
dimensions. In the current cohort payload the legacy
`available_complete_X_views` field records that declared availability; it does
not verify finite values, original numeric equivalence or a qualified axis.
`calculated_X_views` requires actual verified complete-profile receipts;
partial/failed cases remain separate. Do not interpret cache presence as
scientific qualification or count a source card as a completed calculation.

The protected matrix contains per-source raw/SNV geometry, PCA concentration,
optional exact effective dimension, both fixed partition/noise settings, full-axis
neighbor summaries, proximity at all frozen radii, representation agreement,
n/p and exact query/reference support. No new PCA/HDBSCAN/B60 campaign is run.
Native Methods computes distribution summaries, family eta-squared and fixed
absolute-correlation screens. The public correlation selector exposes whether
|r| strictly exceeds .50/.80/.95; it supplies neither signed r nor a p-value.
Constants and insufficient pairs remain unavailable. No coefficient is recovered
from repeated threshold search.

Protected standalone SVG figures show availability, paired raw/SNV response,
sample-size and spectral-width support, and descriptor relationships. Paired
representation changes retain exact source identities. Family comparisons are
unadjusted for n/p and population overlap; strong descriptor association is a
redundancy lead rather than a causal or validated predictive result.

Metadata evidence retains cardinality, missingness and source semantics. B60
evidence is referenced with its original protocol, fractions, exposure and
eligible-ARI support, without pooling incompatible earlier designs. Verified
physical namespaces and package/reference relationships survive reconciliation;
unknown cross-source overlap prevents independent-study inference. No prevalence,
universal structural-risk score or low-risk certificate is produced.

The first adapter pass omitted existing physical-namespace evidence. An explicit
retained revision adds that provenance and recalculates only summaries and
figures. It does not refit spectra or alter historical outputs. Both attempts
remain in the cumulative journal and protected evidence.
