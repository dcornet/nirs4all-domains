# Alpha.13 ecosystem reuse and remaining seams

No upstream repository was modified. Numerical PCA, SNV, HDBSCAN, ARI, nearest
neighbors and descriptive summaries continue through the qualified public native
providers. The native characterization and Methods adapter source bytes are
unchanged from alpha.12. A separate serial CLI transport keeps the DLL resident
while creating fresh contexts for each request. Exact executable parity, including
the full-rank >500-row route, is recorded separately from scientific fit counts.

Domains owns fixed task identities, whole-component draw schedules, rational
joint-inclusion expressions, bounded pair allocation and experimental decisions.
These finite identity operations do not constitute a numerical backend. There is
no Python/Rust PCA, clustering, distance or general probability-distribution
implementation.
