## Minimal real-data contrast candidate (not execution-ready)

Question: does train-fitted X support add useful descriptive information about
matched reference-to-context predictive degradation beyond baseline skill and
training/target-support changes? Rival H0: the marker is noninformative after
those changes; H1: it helps in its declared context; alternative: the effect is
estimator/representation/target dependent. These are new prospective questions,
not retrospective edits of H1–H5 or a claim that an old case is independent.

Proposed eligibility-ordered cohort: at most one source/target from the original
UCPH tablet study and one source/target from the public source-permitted CABO or
manure family already present in R3c. Freeze which second family is eligible
**before** any quantitative outcome review; no favorable-clustering selection
or replacement after a bad result. Use a measured Y, documented original unit,
verified content-bound X/Y alignment and applicable access/statistics rights.
Predicted traits, date/Individual proxies, uncleared 3D-canopy numerical evidence
and CORN are ineligible. Current incomplete specimen/assay crosswalks limit
claims; they do not turn an otherwise credible exploratory alignment into
independent generalization.

The exact canonical dataset/view/version/content hash, target/unit, original
group roster and eligible fold cardinalities must be bound in a task freeze
before an execution request. They are not supplied by a dataset name. If those
fields cannot be established, record the unavailable candidate and request a
different predeclared design; do not silently substitute a source or drop rows.

Use four frozen outer folds per task, one matched reference design and one
deployment-relevant context stress. Retain identical evaluation observations
between designs. Use whole verified dependency components and matched actual
training counts where feasible; report unequal/unattainable counts explicitly.
Unknown physical groups restrict the contrast to exploratory within-source
performance. Random CV is not certified external transfer. Keep raw centered X,
PLS/Ridge identities and **verbatim frozen estimator parameters from the
admitted historical task**; if no such parameter freeze is eligible, submit a
concrete prospective parameter choice for review, with no retained-Y selection.

Per two-task maximum: 2 estimators x 2 designs x 4 folds x 2 tasks = 32 fits;
one fixed training-only target-permutation negative control adds at most 32.
Seed 20261113 is fixed before execution; no reseeding until a favorable null.
Train-mean nulls use only each actual training population. Each of 16 distinct
training scopes gets at most one PCA and two neighbor queries. Freeze all
predictions/lineage before reading retained labels for scoring. No HPO,
preprocessing search, HDBSCAN tuning, VAE/SSL or new expert model.

Primary reporting: reference/stress RMSE, train-mean-relative skill
`1 - SSE_model / SSE_train_mean`, relative RMSE change when reference RMSE is
positive, actual train/evaluation counts and X/Y-support changes. A zero/invalid
null denominator or nonpositive reference skill makes the fragility
interpretation unavailable; retain the errors and adverse case. With only two
source families, report cases and fold variation, not an independent-study
confidence interval, calibrated risk or universal effect. Group-level uncertainty
requires verified resampling units and a separately fixed admissible procedure;
otherwise mark it unavailable. No post-hoc threshold/hypothesis or pooled
per-row significance test.

Expected unfavorable outcomes are scientifically informative: useful prediction
despite support shift; poor prediction without X shift; estimator sign reversal;
all-noise structure with degradation; a training-permutation control occasionally
looking favorable; and an uninformative weak baseline. Keep every admitted case.
The original study overlap prevents calling this independent confirmation of
the earlier discovery. A later untouched-study design remains separate.

The suggested two 3 MiB reservation caps total 6,291,456 bytes, below the last
measured 7,621,678-byte campaign headroom; this is an estimate, not a reservation.
Reconcile actual current ceilings/free space before admission. Reuse cached
originals, no acquisition or fold copies, one task at a time, no automatic retry,
stop at 1 hour or 960 MiB. If input dimensions or exact fits exceed these bounds,
submit a revised concrete task before execution rather than raising a ceiling.
