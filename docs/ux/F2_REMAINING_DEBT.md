# Remaining UX and scientific limits

- Genuine novice/expert and assistive-technology studies are still needed. F2's
  keyboard, axe and screenshot checks measure software behavior, not human utility
  or comprehensive WCAG conformance. Automated incomplete results are retained.
- Shared figures retain their published component contracts. Large/wide technical
  tables scroll within their containers; the full original objects remain lengthy.
  PDF pagination depends on browser/fonts. Full Firefox interaction, Safari,
  tagged accessible PDFs and native screen readers are not qualified here.
- Source scientific prose remains in its original language. New help, interpretation
  explanations, statuses and actions are bilingual; translation is not a rewrite
  of evidence. Source example titles also remain original.
- The isolated-JSON route reads standalone saved reports. Browser envelope round-trip
  import and arbitrary JSON X matrices remain separate future consumer work.
- Metadata import is owner-backed transport, not certification of physical keys,
  source joins or independent specimens. The browser still refuses retained test
  and prediction partitions. A train-fitted browser protocol needs separate owner
  and scientific qualification; F2 does not undertake F3.
- Partial printing deliberately omits full technical reading; complete originals
  remain in HTML/JSON. A short synthesis is never integral scientific evidence.
  Exports omit X but can still disclose names, IDs, PCA coordinates and declarations.
- No target, predictor, validation score, causal shortcut, calibrated risk,
  physical-group inference, preprocessing winner or universally preferred split
  is added. Existing negative/unavailable/contradictory evidence stays accessible.
- F1 and F2 require owner review/merge before their Pages deployment can be claimed.
  A downloadable verified preview is distinct from the current public site.
