# Permanent scientific roadmap

The central objective is to test whether frozen X-only structural descriptors
anticipate predictive fragility and to qualify useful NIRS benchmarks. Goals and
completion measurements below persist across releases; status is supplied by
[campaign evidence](campaign/status.json), not by alpha-number progression.

| Milestone | Goal | Scientific output | Completion measurement |
|---|---|---|---|
| M1 | Characterize every accessible eligible source | Multidimensional X-only profile per source | Eligible source-view coverage, classified by actual evidence completeness |
| M2 | Formulate falsifiable structural-susceptibility hypotheses | Frozen descriptors and explicit scientific predictions | Registered, interpretable hypotheses paired with possible outcomes; preserve H1-H5 |
| M3 | Measure simple models across sources, targets and contexts | Source x target x estimator x evaluation matrix | Number/diversity of valid task comparisons, rather than fit count alone |
| M4 | Determine whether X-only descriptors anticipate fragility | Quantitative H1-H5 assessment, predictive usefulness, contrary cases and uncertainty | Independent study support, defined outcomes, statistical results and falsification evidence |
| M5 | Qualify benchmarks for specified scientific purposes | Frozen within-population, structure-sensitive, domain/population and paired-instrument suites | Evidence adequate for each stated purpose; no unsupported low-risk certification |

A cluster is not a shortcut mechanism; poor transfer is not causal attribution.
Exploratory CV without complete groups remains potentially optimistic. Matched
reference/stress evaluation is required for unconfounded deterioration endpoints.
Independent study units, source views, repeated folds and multiple targets are
counted separately. Missing local metadata does not halt the overall program.

Current evidence: M1 has 137 complete raw/SNV profiles of 171 declared views;
all 164 entries and 2,054 source/target tasks are accounted for. M2 preserves
H1-H5. M3 includes 682 complete primary quantitative reference tasks, paired
raw/SNV context experiments and five declared-plot sensitivity cases. Public
descriptor/outcome confrontation covers 35 views; full authorized local
confrontation covers 48. M4 has exploratory, heterogeneous pipeline and context
effects, with no validated independent cross-study descriptor/fragility
relationship. M5 has provisional task-specific suites.

The next operational priorities are bounded missing-data and low-n qualification,
broader supported stress contrasts, and a prespecified independent confirmation
design. Null, adverse, failed and unavailable outcomes remain visible. Numerical
coverage is regenerated from the campaign status; these milestone goals persist.
