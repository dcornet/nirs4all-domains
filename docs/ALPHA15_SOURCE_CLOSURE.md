# Targeted source/reference closure — alpha.15

Source identity and investigation findings remain confidential. This public
description discloses the admission method, rather than a private candidate list.

Alternative-study selection uses authorization, original conversion/manifest
availability, canonical metadata and target-definition/unit leads, before target
cells or predictive outcomes. Previously unresolved tablet/soil/Cartilage/CORN
cases are excluded from this alternative-selection loop. Ranking and every
inspected document, original-file schema, local locator and hash are protected.
No source identifier is sent to an external service; no new source archive or
spectral matrix is acquired.

The investigation reads local original conversion documents, manifests and
available original-file schemas. Exact original-to-canonical numeric X/Y
correspondence, target units, specimen ownership, assay/reference ownership and
component-safe folds remain separate gates. Canonical sample labels, a generated
row index and a converter's array order cannot close those gates. A schema
inspection is recorded as such and never promoted to numeric equivalence.

The resulting bounded inspection does not qualify a new supervised task.
Specific unresolved links and the documents needed to resolve them are in the
protected report. This is not a claim that evidence is absent elsewhere. No
target cells are decoded and no numeric XY description is manufactured from
unverified mapping. CORN's previous owner exclusion remains in force.
