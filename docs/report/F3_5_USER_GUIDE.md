# Customize report contents

In step 4, **My report**, use **Customize my report**. The read-only core always
contains dataset/source identity, population/representation, live/saved origin,
declared/unknown objective, all findings and conditional warnings, contradictory/
unavailable results, missing information, prerequisites, actual execution status,
limitations and exact evidence references. Recorded values stay with their block.
No importance score decides what is mandatory.

Nested source fields are presented as readable lists/definition fields in custom
tables, with their original identifiers and values. JSON syntax belongs to the
separate complete technical model; choosing fewer supplements does not delete it.

Check additional figures, tables, methods/parameters, neighbors, clustering,
factors, sensitivity, full readiness, provenance or glossary. Disabled options
give the source reason; absent geometry is never reconstructed. The included-
sections preview identifies the mandatory core and selected supplements.

- **Select all available** also explicitly selects machine-evidence printing.
- **Deselect supplements** retains the full mandatory core.
- **Reset defaults** restores historical complete reading, with machine duplicates
  omitted from print. Legacy F2 reading switches become available again.

Choices live only in the current report. Language changes preserve them; intended
use changes retain IDs and refresh availability without numerical refitting.
Loading another dataset resets choices and references.

| Format | Readable content | Original evidence |
|---|---|---|
| Offline HTML | Core plus selected supplements | Complete in the named technical disclosure; no script/network dependency |
| Print/PDF | Selected reading; machine appendix only when requested | Full evidence remains in the HTML file |
| Markdown | Selected sections, with literal figure data/prose | One safely fenced complete JSON model |
| JSON | Integral machine reference plus selection metadata | Always complete, with no scientific field removed |

Use browser print for A4, Letter or another paper size. There is **no page, table,
figure or appendix maximum**. Long content may produce many pages. Analysis byte,
cell, work and worker-time budgets remain separate and unchanged.

Raw X cells and spectral curves remain excluded by default, including SVG exports.
Coordinates, observation IDs, declarations, metadata and source references can
still be sensitive; inspect before sharing and preserve source permissions.
Saved tablet contains no PCA coordinates. User-supplied saved JSON is schema
validated, not authenticated or scientifically requalified; selection adds no fit.
