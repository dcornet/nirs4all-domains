## Visual examination and resulting fixes

Actual screenshots were opened and examined, including desktop/mobile, spectra,
PCA/scree, saved factor/readiness tables, unavailable evidence, dark mode,
French offline report cover/details and print media. Review found overly long
PCA percentage labels and technical-only scalar keys. Six-significant-digit
axis labels and localized metric names with secondary exact IDs correct those
defects. Two-column mobile tables now fit their container; wider factor tables
remain horizontally scrollable. Full precision remains in data tables/JSON.

No artificial visual separation, causal interpretation, cluster robustness or
successive-study claim was added. Technical original prose stays in its source
language. This bounded visual review is not full WCAG or human utility validation.
