# Remaining scope and limits

- Selection changes documentary reading, not diagnostics, scientific importance,
  validation design, source qualification or authorization. Every finding/status/
  limitation remains mandatory regardless of numerical magnitude.
- JSON, HTML technical evidence and Markdown's complete JSON fence remain integral.
  Deselecting reading sections is not a confidentiality or small-file filter.
- Explicit machine printing can be very long. Resource/time/memory failures must
  be reported without silently shortening content. There is no page cap.
- Figures use transported F1 PCA coordinates/eigenvalues. Raw spectra stay screen-
  only; absent saved coordinates are not recreated. Score tables describe the
  PC1/PC2 view, not untransported components.
- No-selection reports preserve historical F1/F2 output and scalar overviews;
  explicit custom readings/detail tables remove the 160-field overview truncation.
- Technical field identifiers and original scientific prose are retained when no
  translation exists. No automatic translation changes the source interpretation.
- PDF text/bounds checks and sampled real raster review do not certify perfect
  typography on every page, tagged PDF, assistive-technology accessibility or
  complete Firefox/Safari printing.
- F3 owner-loader/copy/heap, platform Python maintenance and licence-wording debt
  remain. Preflight and all owner versions/contracts stay unchanged.
- User saved JSON is schema validated, not authenticated or numerically requalified.
  Selection grants no permission to share source metadata or identifiers.
  The accepted standalone saved-schema input is unchanged; browser-demo JSON
  exports are not silently admitted as a new input format.
- Persistent preferences, interactive report JavaScript and another global report
  framework are outside this local, current-report feature.
