# Reading the Domains report

[F3.5 report customization](F3_5_USER_GUIDE.md) adds optional supplements around
the mandatory scientific core. Explicit custom readings follow the selected
sections in print; full original evidence always remains in HTML/Markdown/JSON.
The behavior below remains the historical no-selection F1 reading.

Open an example or import an admissible X source, choose the intended prediction
objective, and download **Offline HTML**, **Markdown**, or **Structured JSON**.
The report is descriptive: changing the objective does not refit measurements.
The HTML works without a server, JavaScript or an Internet connection. Its
original-evidence disclosure sections expand for browser printing; use A4 or
Letter and inspect the print preview before sharing.

Start with **In brief / En bref**, then read the figure's definition, axes,
observation, conditional relevance and limits. Expand **How to read / Comment
lire** for the scientific reading and follow an evidence link to its exact
source object. No link means the source did not supply an admissible identifier;
it does not mean another displayed metric can replace it.

The screen retains the shared interactive spectrum selection, variable-index
zoom, score map and eigenvalue chart. These display controls do not select the
scientific population. A one-component PCA uses a labeled 1D rail; unavailable
PCA has no reconstructed points. Score-map appearance alone does not establish
separation, chemistry, specimen identities or predictive transfer.

Tables distinguish raw and PCA first-neighbor summaries, reference exclusions,
one density partition, noise and original provider summaries. Cluster-size counts
describe acquisitions. For saved reports, separate tables show documented
factor correspondence, density/representation mechanisms, conditional D2 claims
and D6 prerequisites when carried. Input availability, protocol qualification,
authorization and receipt-backed execution are independent dimensions.

**Saved evidence / Preuves enregistrées** retains original source wording and
historical measurements; it is not a browser refit. The public tablet example's
six intention variants are not six studies. Missing spectra, metadata, scores,
independent-study identities or predictive comparisons stay missing. The browser
checks declared hash-binding contradictions but does not authenticate an imported
report's author or recompute its original scientific qualification.

Presentation explanations, headings, number formatting, glossary and availability
guidance switch between French and English. Source quotations, reasons, technical
identifiers and exact objects remain unaltered. Technical parameter identifiers
are deliberately retained beside human-readable labels.

Raw spectral cells and curves are **never included by default** in any report
format. PCA coordinates, observation identifiers, source/deployment declarations,
metadata and original report references can still be sensitive. Inspect an
export before redistributing it; rendering does not grant source permissions.
Detailed spectral-figure export is deferred, rather than hidden inside an SVG.

The [matrix](F1_FIGURE_TABLE_MATRIX.md) and
[validation record](F1_REPORT_VALIDATION.md) define the tested scope. F1 improves
fidelity and readability, not the scientific coverage of the browser engine or
the empirical usefulness of warnings to human experts.
