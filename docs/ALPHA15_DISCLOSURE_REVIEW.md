# Disclosure review — alpha.15

The existing alpha.14 closed-schema, exact-byte and cumulative review mechanism
is reused. This release creates no new privacy framework and claims neither
anonymity nor differential privacy.

A small selection of meaningful aggregate drafts is reviewed locally. These
drafts remain local because source aggregate rights, participation permission
and joint-release clearance are not established for every contributor. No
publication attestation is inferred from the owner's local-analysis attestation.
No private numerical file, figure, source count, participation list or sanitized
substitute is added to Git or CI. Rejection leaves scientific evidence intact.

Exact drafts, hashes, rationale and local-only decisions are protected. Earlier
public outputs remain linkage context: distinctive n/p, family combinations,
extremes and overlapping marginals need review even when a scalar is aggregated.
No approved public release is appended to the disclosure ledger.

Outgoing engineering source/docs/tests use a finite reviewed provenance roster.
The existing guard is parameterized only for a new roster and separate signed
review location; the previous signed review remains unchanged. Actual index
blobs, packages and public CI are checked independently of scientific execution.
