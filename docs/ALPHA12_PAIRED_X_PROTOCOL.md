# Original-keyed litter X contrast — domains.alpha12.paired_x.v0.1

Frozen before the new contrast. Choose litter because original intact/ground
spectra share audited bag IDs and complete equal axes, independently of any
historical predictive response. Read only original `ID` and 400–2400 nm fields;
do not materialize reference or trait columns. Exact source files were already
retrieved and pinned by Datasets in alpha.11; no acquisition occurs.

Preserve the full parent populations, 322 intact and 321 ground. The explicitly
paired task compares the 321 shared original IDs, sorted and joined by key.
The intact-only ID GEN_1_BEPA_7 remains reported and is never removed from its
full-source primary profile. This intersection defines paired evidence; it is
not a budget-driven source truncation or an independent study.

Fit the frozen raw/SNV protocol separately to each paired view: four PCA and
eight HDBSCAN attempts, plus complete-axis/PCA native neighborhoods. Compare
variance concentration, normalized neighborhoods, exact ranks, partitions and
noise on identical objects. These are same-object preparation differences
under separately fitted descriptive representations, not new-object validation
or a prospective train-reference transfer assessment. Any historical retained-X
support result keeps its original train-only state and separate post-response scope.

Store source/axis/key hashes, parent and paired counts, missing keys, providers,
timings and explicit interpretation. No X, target values, model or PCA score
matrix is added to portable reports. Nmass and other nonselected cells may be
invalid arbitrary strings without affecting extracted X or pairing; adversarial
field-isolation tests qualify that claim. This is field-level exclusion, not
a promise that the CSV's storage bytes contain no other fields.
