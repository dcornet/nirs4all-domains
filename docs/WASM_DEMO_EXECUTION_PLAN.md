## Expected scientific behavior, before implementation tests

- A complete finite X population imported by the published IO/Formats browser
  APIs is validated and characterized by a real Domains Rust/WASM protocol over
  the public Preflight MethodsProvider and actual Methods WASM kernels.
- Preserve original observation order, axes, declared roles and partitions.
  Observation keys are not physical specimen identities. No inferred joins,
  imputation, generated split, automatic preprocessing choice or silent sampling.
- Full-X descriptive fits are explicitly transductive/descriptive. They establish
  neither predictive performance nor independent transfer. A changed intended use
  changes only conditional interpretation, with zero additional numerical calls.
- PCA, neighborhoods and density partitions retain separate definitions/scopes;
  density settings are not spectral representations. All-noise and contradictory
  evidence stay visible; missing moments cannot be derived from truncated PCA.
- Five-family saved D1 warnings and D2/D3/D6/D6.1 companions retain their original
  contracts. The live portable interpretation is qualified only for the explicit
  subset verified against Python reference behavior. No blanket parity claim.
- Unknown metadata and unsupported kernels produce reasoned unavailable states.
  A documentary proposal or user declaration is never an executed validation,
  certified physical mapping, authorization grant or failure probability.
- Exports share one semantic model, distinguish live/saved provenance, exclude raw
  X by default and escape user strings. Standalone HTML is genuinely offline.

Parity: exact order/IDs/states/settings/hash identity; analytical finite scalars
use absolute tolerance 1e-10, PCA eigenvalues/distances use absolute/relative
1e-8, and sign-invariant PCA geometry is compared rather than arbitrary signs.
Any definition or population mismatch blocks the corresponding capability.
These tolerances are engineering qualification choices, not scientific risk gates.
