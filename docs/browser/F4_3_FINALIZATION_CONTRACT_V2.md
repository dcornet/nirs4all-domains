## Portable presentation v2

The PDF is a dedicated paginated scientific reading, never the interactive
DOM. Preserve dataset/population, settings, all requested representations and
their availability/refusals, unfavorable findings, recorded figures, limitations
and provenance. Compact tables use at most 12 rows and 8 columns; larger detail
is explicitly represented by its complete CSV companion and exact row count.
No winning representation, new metric or hidden print annex is introduced.
Figures with more than 1,000 points are explicitly deferred to complete CSV/
JSON rather than silently subsampled. Detailed values are not duplicated in PDF.

CSV is UTF-8/RFC4180 long form: stable evidence/result/representation IDs,
RFC6901 source pointers, optional carried observation/axis keys, value type and
exact serialized scalar. Null, empty arrays/objects and unavailable statuses are
explicit. Ordering follows the original evidence; arrays preserve order. Only
the existing permission-filtered report model is accepted; no raw X/Y, newly
authorized metadata or independent identity inference. CSV preserves complete
authorized evidence; selected annexes govern PDF detail, not export permission.

The manifest documents schemas, scopes, CSV sections/ranges/counts and JSON
counterparts. Independent PDF and CSV downloads remain available. A portable
ZIP contains A4/Letter PDFs, CSV, structured JSON and manifest with relative
paths. PDF annotations point to actual extracted companions; visible filenames
remain useful when a viewer blocks links. Historical HTML/Markdown/JSON remain
available with their original semantics.

and openly licensed embedded font are permitted if necessary for actual Unicode
