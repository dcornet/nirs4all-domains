# Original-reference closure — alpha.16 prospective protocol

Expected scientific behavior is fixed before new source-specific tests and
target decoding. The alpha.12/13 H1–H5 bindings, response formulas, numerical
definitions and source-role rules remain unchanged. Existing alpha.15 admission,
keyed equivalence, dependency/fold checks and native fitting are reused.

Original observation correspondence, physical ownership, reference/assay
ownership, target semantics/units and predictive independence are separate
claims. A generated index, row count or converter ordering cannot establish any
missing claim. Original documented order may support a correspondence only with
an explicit source contract and verification; it never certifies independence.
Likewise, a matching basename elsewhere in an extracted/cache tree is only a
locator hint. Require a declared manifest/source identity and content binding
before treating that file's schema or values as original-source evidence.

For each existing candidate, reconcile exact prior receipts and inspect only
the unresolved original links. Freeze an investigation limit and stopping rule.
After a bounded unsuccessful investigation, retain a precise owner-evidence
request and move to a pre-outcome-selected eligible alternative. Do not select
by published or private predictive scores. CORN's owner hold remains active.

Inspect structured containers selectively with existing qualified readers.
Separate metadata/X projection from target decoding. Reject a loader that
materializes an entire mixed X/Y object to get around the target boundary.
Freeze exact permitted development/retained membership, target columns, units,
original keys and missing-reference policy before numeric target access.

Test shuffled keyed joins, duplicate/conflicting keys, wrong specimen/reference
attachment, shared assays, technical-repeat boundary crossing, missing donor or
batch ownership, numeric target identifiers, ambiguous units, mismatched axes
and incomplete reference maps. Comparing two absent fields is not success.
Reject unrelated files with the same basename, generated observation labels mistaken for specimen keys and
source-ID mappings contradicted by the original manifest. Missing evidence
remains unavailable, rather than false zero or fabricated independent per-row events. Preserve all rows;
any exclusion needs a prior source-based policy and a reported denominator.

Valid X-only evidence may coexist with unavailable XY. Verified development-only
XY may coexist with unavailable supervised evaluation. Numerical correspondence
alone does not supply physical/reference dependency closure. Actual supervision
needs original-supported components, feasible grouped nested folds, a meaningful
reference/stress comparison and whole-component size controls. Insufficient
groups or unmatched evaluation populations cannot produce a pure structural
contrast or independent-study inference.

Identity sets, source bytes, axes and frozen digests compare exactly. Numeric
parity uses exact documented transport representations where possible; a source
conversion tolerance must be justified and frozen for its specific adapter
before values/results are examined. Native analytical synthetic controls retain
absolute 1e-10. No historical tolerance or hypothesis threshold changes.

Every unresolved candidate records the missing relationship, exact inspected
document/file receipt, expected resolving evidence, local availability, need for
owner clarification, tier-specific consequence and next action. Source-specific
results and requests remain protected; this public document contains no private
candidate roster or findings. New real fitting requires separate explicit owner
authorization after the complete exact protocol and costs are reviewable.
