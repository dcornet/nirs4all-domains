# Adaptive public campaign — domains.adaptive_structure.v0.1

Frozen before alpha.11 numerical execution. Baseline ece7788 and all 177 earlier
protected files are retained; the preservation manifest now covers 224 files.
Before the owner's addendum only read-only source audits, preservation and disk
measurement were complete. No acquisition of spectral matrices or fit was running.
The addendum changes upcoming work, without changing an executed protocol.

The pinned catalog has 42 public entries. Every entry receives a record, including
dimension, access, axis, identity and budget failures. Prior metadata admissions
are reused. Public tier alone does not establish rights: original open licenses
are checked before new analysis. Existing local spectra are read-only inputs;
Datasets owns any new acquisition. No restricted source is downloaded.

X0 does not require Y, metadata or physical identity. Scoped observation keys are
explicitly distinguished from verified physical identities. No aggregation or
physical-duplicate inference follows from spectral proximity. Complete axes and
populations are retained. The native Methods FlexiblePCA adapter supplies a
centered, unscaled maximum-20-component representation, full trace and optional
exact full moments. Missing full moments affect only effective dimension.
Native nearest neighbors exclude the observation itself, not an invented animal
or plant. Distances in the retained projection and original spectra are separate.
Raw nearest neighbors run only when n*n*p <= 250 million; projected neighbors
when n*n*min(20,p,n-1) <= 250 million. Full matrix <= 10 million cells and affine
PCA query p*p*k <= 250 million. Unsupported dimensions are explicit, never sampled.

Distance summaries use Methods. Raw-distance proximity is reported at
1e-10, 1e-8 and 1e-6 times sqrt(full covariance trace), with exact counts and
the normalization stated. These are numerical sensitivity checks, without a
physical identity or laboratory precision interpretation. A zero projected
distance does not establish equality in the original spectral space.

HDBSCAN uses existing native parameters (8,4,EOM) and (12,4,EOM), no single
cluster. Full-population labels, noise fractions and membership summaries are
descriptive. Parameter agreement uses native ARI. Without 100 supported
component-resampling fits no stability classification is issued. A continuum,
all-noise or absent metadata cannot establish low structural dependence.

X1 reuses documented historical train-fitted coverage, or newly admitted splits;
no held-out cluster membership is invented. XY requires keyed permitted training
targets; full-development X-derived association is descriptive, with zero native
unrestricted permutations. XYM requires declared factor provenance. MODEL retains
the stricter physical/reference and fold admission. Susceptibility, association
and estimator dependence remain distinct states. No universal score is calculated.

Freeze candidate intent: Brookhaven eight-crop leaves, original nitrogen dry-mass
percent; Cedar Creek/Minneapolis litter, original nitrogen concentration (unit to
be verified). Selection uses source/material/identity contrast, never model scores.
Garrett is investigated as a non-leaf alternative; its original publication says
MIR while the catalog leaf says VISNIR, so modality correspondence needs proof.
The litter source explicitly names intact/ground views of the same objects: these
cannot count as two independent populations. Admission and exact designs are
frozen separately after original-key inspection and before model scores.

Execution remains serial under the existing alpha.9 cumulative journal. Owner
approved workspace ceiling 13,336,807,105 bytes; campaign 512 MiB, task 256 MiB,
essential evidence 4 MiB/task, free reserve 2 GiB/volume. JSON is streamed to the
native process to avoid persisting duplicate matrices. Source bytes, controllers,
provider DLL and configuration determine checkpoint reuse. Original data and
historical outputs are never deleted or migrated.

Expected controls: separated groups versus continuous gradients, imbalanced
support, unknown-identity quasi-duplicates and independent coincident spectra
remain descriptive. True repeats need declared identity for leakage conclusions.
No Y implies unavailable association; independent Y must not manufacture an
association. Group-only, within-group and mixed mechanisms retain distinct
interpretations. Missing metadata cannot suppress X0 or imply safety. Missing
independence blocks MODEL only. Rank/budget failures remain visible. X0 accepts
no target field, making retained-Y influence impossible at its input boundary.
Analytical scalars use abs 1e-10; identity/hash checks are exact; same-input
native replay is exact. Existing adaptive replay tolerance remains 1e-9.
