# D1 conditional structural warnings v1

This increment turns qualified existing measurements into five optional,
deployment-dependent methodological cautions. The public Python API/CLI and
content-bound JSON/Markdown companion preserve legacy reports, predictions and
metrics. The schema, five qualified public factor snapshots and worked tablet
example are in [the API documentation](STRUCTURAL_WARNINGS_API.md).

Physical dependence needs declared meaningful units or a verified Preflight
identity/reference finding. Factor-PC association can coexist with weak cluster
agreement. Representation, neighbor, partition and density-setting sensitivity
remain distinct. Support interpretation requires training-fitted operations and
observed evaluation X. Missing context identifies questions, without classifying
a dataset as dangerous. No model, PCA, cluster fit, preferred preprocessing,
universal splitter or calibrated risk probability is added.

## Limits and next product priority

Bindings retain declared provenance; this interpreter does not independently
authenticate source roles or identities. Single-axis support is incomplete.
Factor association is descriptive and may reflect crossed/confounded effects.
Counts of profile rows are not independent studies. Original-database counts
remain unavailable without an authoritative grouping. The frozen linear RMSE
skill and squared-ratio skill retain distinct names; neither is a risk score.

Next priority is D4: qualify these optional D1-D3 companions with one concrete
report consumer and user-supplied deployment context. Further scientific fitting,
new diagnostic kernels and broader guidance require their own scoped work.
