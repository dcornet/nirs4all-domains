# Ecosystem work proposed without upstream changes

Datasets could expose source-scoped access/analysis/publication/redistribution
decisions with evidence references, confidentiality scope, lawful owner-provided
cache admission and modality/axis provenance. These must remain separate from
catalog tiers and software licenses. Source metadata availability is not proof
of original physical/assay correspondence.

Formats/Datasets selective-field contracts remain useful for original structured
files whose spectral and reference fields share a container. Domains still uses
authorized X-only canonical inputs and does not add a vendor decoder or materialize
mixed MATLAB objects to bypass prior target-access restrictions.

Domains owns task-specific pseudonym scopes, declared relationships, external
evidence transport and disclosure decisions. Reusable fit/neighbor/statistical
kernels remain in Methods; intrinsic qualification remains in Preflight; later
grouped model selection/refitting remains in DAG-ML. No upstream repository or
remote issue was changed. No new numerical library or third crate is justified.

The present ACL/HMAC model protects accidental application disclosure. Future
multi-user deployments need a separate service/key-management and reviewer
authentication design. Conservative cumulative release review is not a formal
privacy accountant, and no differential privacy claim is made.
