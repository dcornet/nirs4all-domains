# Alpha.13 target-free source extension protocol

Expected behavior, fixed before new real profiles and tests: admit a canonical
X-only view when exact source provenance and three independently recorded rights
dimensions authorize access, local analysis and nonreconstructive statistics.
Catalog private/public tier alone is neither authorization nor disqualification.
Raw redistribution remains unknown and is not requested. Permission evidence and
the declared original-source URL must agree before opening X.

Use only the existing canonical `X.csv`, its complete declared axis and scoped
observation IDs. Read no Y table, target object, reference value or model score.
Source scripts/cards/manifests are provenance metadata and are not executed.
UCPH's public-use statement scopes the pharmaceutical and Abisko-soil originals;
OHPL's documented soil origin and GPL distribution provide the additional package
lineage. Neither a matching shape nor a package-paper DOI proves original numeric
equivalence, specimen identity or source-reference alignment.

The pharmaceutical MATLAB Matrix mixes 404 bands and three nonspectral fields.
No complete Matrix or Eigenvector soil object may be decoded during this phase.
Only source/archive headers and label metadata are inspected. A canonical view
may receive observation-conditional X characterization while exact original
numeric equivalence remains explicitly unavailable. No original-to-canonical row
join is made. Synthetic canonical IDs do not become physical specimen keys.

The complete canonical populations are 310 tablets × 404 bands and 108 soil
observations × 700 bands. Preserve each axis and unit. Native raw/SNV reference
PCA, neighborhoods, HDBSCAN, summaries and ARI reuse alpha.12 unchanged. The same
queries and full reference populations apply in both representations. Explanatory
metadata without independently keyed ownership stays unavailable.

No supervised admission follows from X-only admission. Missing original physical,
plot, assay and retained-reference closure keeps MODEL unavailable. Soil's 36
declared plots are not assigned to consecutive triples. Do not select sources or
representations by any predictive outcome. The separately frozen revised design
must precede stability fitting; original numeric equality is not silently assumed.
