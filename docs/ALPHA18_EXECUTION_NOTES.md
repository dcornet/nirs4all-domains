# Prospectively documented execution qualifications

Before decoding any new Y, the identity-only scan found four source views
blocked by the constant marker `historical_splits_documented_not_applied`.
Canonical M and the catalog's explicit `applied=false`/documented-origin text
agree that this describes historical terms, without declaring actual train/test
memberships. An additive signed scope continuation recognizes this exact marker
as no applied split. Original freezes, artifacts and adapter bytes remain intact.
This admits exploratory development CV, never an independent-generalization
claim. Known native memberships in other sources remain excluded as specified.

The deeper selection adds declared species/genus, source project/year and
original scale as possible exploratory contexts. Selection was frozen before
new supervised outcomes: six source/target tasks met complete metadata,
nested-component and affordable exact-size-control support. Their context
interpretation is declared, not an assertion of a causal nuisance mechanism.
Three train-only diagnostic PCAs per task (18 maximum) reuse FlexiblePCA's
public fit/transform; evaluation is never refitted. The univariate first-PC
training range is a limited support descriptor, not complete geometric coverage.
No extra source acquisition, model family, storage ceiling or reservation
increase is introduced. The prospective selection and continuation are linked
from the campaign matrices.

Whole-workspace accounting costs about six seconds per scan. The existing
StageStore therefore measures its controlled output region per task, retaining
the same journal/reservation limits. The authoritative combined-storage guard
still counts the full workspace, protected evidence and participating original
files before every source and conservative batch (32 reference tasks at most).
Its look-ahead covers the full batch reservation. This avoids thousands of
redundant whole-tree scans without changing source participation or ceilings.

After the first forty X tasks, persistent output was reduced to descriptor rows,
native profile fingerprints and original axis labels, rather than retaining
all neighborhood identity panels. This anticipates larger census outputs under
the unchanged evidence cap. The initial controller is archived and its hash
and continuation recorded locally. Earlier artifacts are untouched. Native
requests, query identities, PCA/HDBSCAN parameters and scientific rows remain
identical; completed computations are not repeated. Partial representation rows
remain usable when the paired representation fails.

The final pre-target check also reuses the project's existing sealed historical
memberships, beyond native split columns. An identity-only projection strips
scalar Y and X arrays before decoding historical task JSON. No retained outcome
is accessed. The union of previously sealed memberships is carried forward:
91 Perten specimens, 24 litter specimens, and historical CA2023 plots/objects.
Existing declared experimental components are reused. This can reduce the new
development population relative to any one historical seed; no old split is
reset. Three views with incomplete binding to known retained populations remain
locally unavailable for supervision; their X profiles remain usable. The
unexecuted initial stress selection is preserved and superseded prospectively
by a selection respecting these updated components/populations, before any new
target decoding. This is retained-test protection, not a new original-source
crosswalk investigation or a biological-independence claim.

After the primary campaign, feature-free training-mean OOF can still be
completed for targets whose X contains nonfinite cells. This uses the SAME
already frozen folds, development population and native summary/score kernels;
no feature imputation or PLS/Ridge retry. At most 416 target-only continuations,
128 KiB each (54,525,952 bytes), remain inside the existing reservation ceiling,
even with the five-task SNV stress extension. They preserve successful target
evidence when a feature-dependent stage fails. This adds zero model fits and
does not make the unavailable spectral regressions complete.

The initial numeric-type/name screen was incomplete: a full catalog-name audit
found sample counters, genotype codes and contextual/QC fields among declared
numeric targets. The explicit semantics-v2 correction excludes 18 identifiers/
categorical labels in total and separates context, derived and unresolved QC
endpoints from primary quantitative synthesis. It is metadata-driven, without
using model scores; already executed diagnostics and their reservations remain
intact and separately counted. Not-yet-started workers skip invalid identifiers.
The original controller and semantic freeze are preserved with an additive
continuation. Before any stress fitting, target semantics are corrected on the
same five source/context populations using a fixed nitrogen/drug/moisture/LMA
priority. This yields N, leaf LMA, LMA, nitrogen dry-mass percent and tablet active
concentration rather than coordinates, pot size or arbitrary first numeric fields.
No old result or registered H1-H5 definition is rewritten. Proposed upstream
work is correcting auto-generated catalog roles/types, not changing Datasets here.

The initial raw-stress watchdog exposed a race in the historical OS memory
helper: each thread creates a different ctypes structure class and mutates the
cached function prototype. Completed raw outputs and their final OS lifetime
peaks remain intact; those peaks are below 2 GiB. Continuous watchdog faults are
recorded rather than presented as clean enforcement. A version-local helper
initializes independent stable function prototypes once; 400 concurrent reads
across four threads qualify it before SNV/grouped work. No numerical algorithm,
completed outcome, source or representation parameter is changed or rerun.

Local Rust validation encountered a GCC installation-path issue: the implicitly
inserted `default-manifest.o` path split at the space in the workspace name.
Using the compiler's short executable path alone did not fix its internal
library lookup. A process-local `LIBRARY_PATH` using the existing native 8.3
library-directory path resolves it. No compiler copy, migration, global config,
Rust protocol or numerical source change was needed. Failed validation logs
remain alongside the completed gates.
