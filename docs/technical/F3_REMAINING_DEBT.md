# Remaining technical debt after F3

- The locked IO/Formats distributions still need the verified Node-glue bootstrap
  adapter. A public, versioned browser entry and compatible typed numeric transport
  would remove more coupling. Those are owner contracts to describe, not implement
  in Preflight/IO/Formats here. No future/experimental owner code is consumed.
- New IO 0.3.3 / Formats 0.2.17 and Methods 1.3.17 are not silently admitted.
  Materialization, identities, representation, provider versions and hash changes
  need separate qualification. Preflight 0.1.6 / ABI 2.20 is an absolute F3 lock.
- Native JSON/nested-array/FFI copies remain. Small engineering measurements are
  not a whole-bank RAM guarantee. Product byte/cell/work limits are not RAM quotas;
  strict per-process allocation containment is outside a browser worker's API.
- Grouped worker spans do not expose pure module initialization, decode, assembly,
  owner numerical time or pure React commit cost. These measurements remain
  explicitly unavailable instead of being estimated from unrelated totals.
- Rand 0.8.5's reviewed advisory is unreachable under the current no-log/seeded
  usage. It is not patched or hidden; enabling different downstream features needs
  a fresh review. Frozen random streams are not changed opportunistically.
- Python patch availability differs across hosted OSes. Broader Python/NumPy/
  pandas/scikit-learn migration and full MSRV execution remain separate technical
  work. Candidate numerical-oracle versions stay the previously qualified cohort.
- Top-level action SHAs do not freeze upstream composite-action subreferences,
  OS images, compiler download infrastructure or GitHub services. The new Pages
  deployment path cannot be executed before owner merge; only build/preview and
  the existing public deployment are qualified here.
- Native assistive technology, tagged PDFs, broad Firefox/Safari interaction and
  genuine expert/novice usefulness remain outside this engineering qualification.
- Optional report appendix checkboxes remain separate product work. The complete
  report is integral; no arbitrary page cap, hidden evidence or F3 export rule is
  introduced. Source permissions and historical evidence remain applicable.
- No new train-fitted browser protocol, scientific diagnostic, model, uncertainty
  interpretation, calibrated risk or physical-independence assertion is added.
