# Embedded PDF font

Noto Sans Regular, SIL Open Font License 1.1; [license](OFL.txt).
Unmodified source:
https://github.com/notofonts/noto-fonts/blob/ffebf8c1ee449e544955a7e813c54f9b73848eac/hinted/ttf/NotoSans/NotoSans-Regular.ttf

SHA-256: `b85c38ecea8a7cfb39c24e395a4007474fa5a4fc864f6ee33309eb4948d232d5`.
The font is embedded as a subset in PDFs. Its license accompanies portable
packages and the distributable notices. PDF-LIB/fontkit are pinned by the demo
lockfile and serialized lazily; scientific providers and their locks are unchanged.

The published fontkit fork ships no standalone license file. Its original README
and MIT declaration are copied into the distributable notices alongside the
registry metadata; no missing copyright attribution is invented.
