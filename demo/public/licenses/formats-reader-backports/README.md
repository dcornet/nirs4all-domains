# Formats reader-backport notices

The exact MIT/Apache license texts for `hdf5-reader` and `netcdf-reader` are
copied unchanged from the published `@nirs4all/formats-wasm@0.2.14` package's
`reader-backports/` directory. PROVENANCE.json binds their bytes to the pinned
npm archive/integrity. They supplement the package's third-party notice and the
application's shared license-family texts; no parser implementation is copied
or modified. These files remain separate from generated package notices.
