# Domains working conventions

## Protocol and scientific boundaries

Before protocol changes read [README](README.md), [architecture](docs/ARCHITECTURE.md), [reuse matrix](docs/METHOD_REUSE_MATRIX.md#generic-diagnostic-boundary) and [scientific protocols](docs/SCIENTIFIC_PROTOCOLS.md). The ignored Word-plan attachment is historical, not a runtime prerequisite.
Domains owns structure/population/evaluation protocols; Methods owns numerics, Preflight intrinsic qualification, DAG/model APIs fitting/selection. Reuse public Methods/Preflight APIs; never copy numerical algorithms into Rust or Python. Keep two crates until a consumer justifies another; Python is transport/batch/protocol assembly, not numerics; synthetic test-data generation is not a numeric backend. Require separate source/ABI/binding/publication/executable evidence; availability is not scientific qualification.
[Upstream proposals](docs/UPSTREAM_DEPENDENCIES.md) need explicit current authorization for changes; history does not veto authorized Root owner fixes.
Keep dataset/content version/source/target/split/policy, axes and reference/group/indivisible identity closure explicit. Prefer declared identities. Same-export X/Y/M positional alignment needs verified content-bound counts/order/exclusions/no independent sorting/filtering; exploratory only, not physical/reference independence. No invented partitions or implicit imputation/source fusion.
No retained-test fit or Y_test selection. Behaviour/adversaries, version/tolerances precede protocol changes. Keep training scope, distinct algorithms/oracles, failures and frozen history; never rewrite/rebless for green. [Product/research ownership](docs/PRODUCT_RESEARCH_BOUNDARY.md#ownership-matrix) and protocols retain named providers, not universal risk claims.
Keep JSON Schema/status/reason/value invariants: no NaN/Inf or arbitrary scores; noncomputed values need null/reason. Findings state observation, confidence, consequence and action; confidence is not probability.

## Gates, privacy and identity

From checkout/package/native env use [complete CI](.github/workflows/ci.yml): provider/libs and N4DOMAINS_BIN/platform suffix before bridge tests; locked/ignored native, schema/no-diff/registry/bank/JSON gates. CI pins are context, not host/green claims; see [validation](docs/VALIDATION.md).
Keep Cargo.lock; no absolute development paths in distributable manifests. Datasets owns cache; results/, .audit/, .tools/, .venv/ stay ignored. [Storage/replay](docs/STORAGE_AND_REPRODUCIBILITY.md#budget-checkpoints-and-concurrency) retains charged failures/history, reserves, source rights/frozen evidence.
Authorized private-root inspection uses scripts/inspect_private_roots.py; never dump values, project JSON first. This grants no config read. Ordinary source-permitted aggregates/protected historical exports keep distinct owner conditions.
Use single-agent work unless the user requests delegation. Respect dcornet/nirs4all-domains identity; verify git identity/permissions, never invent an author, change global config or copy a sibling credential/author rule.
Historical only: 5,000,000,000-byte alpha grant (staged plan, report usage/limits/scope, reserves/history/access; ask above cap) and 2026-10-16 creation/first-push confer no current Root budget/Git grant.
[LICENSING](LICENSING.md) retains current `CECILL-2.1 OR AGPL-3.0-or-later`, versus AGPL-only through Rust alpha.16/bridge 0.1.0a21, dependency/binary notices and source data/report licences/access restrictions.

## Working rules

Read applicable instructions first and preserve dirty work. If `../AGENTS.md` exists, read it within the current user scope; this file also works alone.
Use CodeGraph FIRST only with this checkout's own `.codegraph/` (exact projectPath or local CLI); never auto-index or use an ancestor index. Source, tests and builds are final authority.
Record actual commands, exits and skips. Keep secrets, private data and build output out of Git. Examples grant no install, network, science, publication, hosting, frontend or Git authority.
All project content, including UI text, docs, tests, reports, PRs and commits, is English; conversation may be French. Preserve names, identifiers, quotations and provenance.
